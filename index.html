pymeteo

Pointwise meteorological diagnostics with explicit string unit parameters. Runtime dependency: NumPy. PyPI name pymeteo-kit; import name pymeteo.

No Pint, no Sounding/Wind objects, no MetPy, no NCL runtime. Not an I/O, plotting, or full CAPE/CIN package.

Install

pip install pymeteo-kit

Python 3.6+. On 3.6 the NumPy pin is 1.19.x. Building from a git checkout needs Python 3.8+ (hatchling ≥ 1.18); 3.6/3.7 should install the wheel.

Example

import pymeteo as pm

td = pm.dewpoint_from_relative_humidity(
    18.0, 46.5, temperature_unit="C", humidity_unit="%"
)  # about 6.30 °C

si = pm.showalter_index(16.6, 0.6, -15.9, temperature_unit="C")  # about 1.1

km = pm.earth_distance(39.9, 116.4, 31.2, 121.5, output_distance_unit="km")

from pymeteo.ncl import dewtemp_trh
td_k = dewtemp_trh(18.0 + 273.15, 46.5)  # K in, K out

Defaults: temperature C, pressure hPa, wind m/s, relative humidity %, mixing ratio kg/kg, distance km (thickness defaults to m), angles in degrees. Unknown strings raise pymeteo.UnitError.
