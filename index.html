pymeteo

Dewpoint, vapour mixing, potential and equivalent potential temperature, LCL, wet-bulb, visibility, Showalter / K / A / TT / SWEAT / lifted index, wind, geodetic distance, sea-level pressure, NWS heat index and wind chill, Coriolis, hydrostatic ω ↔ w.

Python 3.7+. NumPy only. Units are strings on the call. Returns float or NumPy arrays.

Example

import pymeteo as pm

td = pm.dewpoint_from_relative_humidity(
    18.0, 46.5, temperature_unit="C", humidity_unit="%"
)
si = pm.showalter_index(16.6, 0.6, -15.9, temperature_unit="C")
u, v = pm.uv_from_speed_direction(10.0, 270.0, speed_unit="kt")
km = pm.earth_distance(39.9, 116.4, 31.2, 121.5, output_distance_unit="km")

Defaults: temperature C, pressure hPa, wind m/s, relative humidity %, mixing ratio kg/kg, distance km (thickness defaults to m), angles in degrees.

Install

pip install pymeteo-kit

import pymeteo. NCL builtin names live in pymeteo.ncl, not at the package root.
