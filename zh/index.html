English

pymeteo

点上气象诊断函数，使用明确的字符串单位参数。运行时依赖只有 NumPy。PyPI 发行名 pymeteo-kit，导入名 pymeteo。

不提供 Pint、Sounding / Wind 类封装、MetPy 或 NCL 运行时。不是 I/O、绘图或完整 CAPE/CIN 探空包。

安装

pip install pymeteo-kit

Python 3.6+。CPython 3.6 上的 NumPy 上限是 1.19.x。从 git 检出构建需要 Python 3.8+（hatchling ≥ 1.18）；3.6 / 3.7 请安装 wheel。

例子

import pymeteo as pm

td = pm.dewpoint_from_relative_humidity(
    18.0, 46.5, temperature_unit="C", humidity_unit="%"
)  # 约 6.30 °C

si = pm.showalter_index(16.6, 0.6, -15.9, temperature_unit="C")  # 约 1.1

km = pm.earth_distance(39.9, 116.4, 31.2, 121.5, output_distance_unit="km")

from pymeteo.ncl import dewtemp_trh
td_k = dewtemp_trh(18.0 + 273.15, 46.5)  # 开尔文进、开尔文出

默认单位：温度 C、气压 hPa、风 m/s、相对湿度 %、混合比 kg/kg、距离 km（气层厚度默认 m）、角度为度。无法识别的单位抛出 pymeteo.UnitError。
