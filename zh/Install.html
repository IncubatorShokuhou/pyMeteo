安装

English

Python 3.7+。运行时依赖只有 NumPy。

pip install pymeteo-kit

PyPI 发行名是 pymeteo-kit（pymeteo 已被占用）。导入：

import pymeteo as pm

从 git 检出：

pip install -e ".[dev]"
pytest

发布走 GitHub Actions 上传 PyPI。见 发布与贡献。
