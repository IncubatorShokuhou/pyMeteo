# Wiki source

Bilingual function notes for pymeteo (`pymeteo-kit`). English pages are `Home.md`, `Install.md`, …; Chinese pages are `Home_zh.md`, `Install_zh.md`, ….

These files are the same text pushed on `gh-pages` under `wiki/` for the GitHub Wiki remote (`*.wiki.git`). GitHub’s wiki git repository is created only after the first page exists in the GitHub UI; until then browse this directory.
