# Install

[中文](Install_zh)

Python **3.7+**. Runtime dependency: NumPy only.

```bash
pip install pymeteo-kit
```

PyPI name is `pymeteo-kit` (`pymeteo` was taken). Import:

```python
import pymeteo as pm
```

From a git checkout:

```bash
pip install -e ".[dev]"
pytest
```

Releases go to PyPI from GitHub Actions. See [Publishing](Publishing).
